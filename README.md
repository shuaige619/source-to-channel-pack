当中文电商与自媒体运营需要把同一份已给定商品母稿和品牌约束改编为小红书、公众号、口播文本，保持参数、测试条件和承诺一致并交付内容文件时使用。

## 适用场景

当中文电商与自媒体运营需要把同一份已给定商品母稿和品牌约束改编为小红书、公众号、口播文本，保持参数、测试条件和承诺一致并交付内容文件时使用。

## 安装与使用

```sh
git clone https://github.com/shuaige619/source-to-channel-pack.git
cd source-to-channel-pack
```

将此目录按宿主支持的方式登记为本地 Skill，或把 [SKILL.md](SKILL.md) 交给支持 Agent Skills 的助手读取。保留 `scripts/`、`references/` 等配套目录的相对位置；下载完成不代表宿主已加载。

需要能读取本地 Markdown 的 Agent 环境。其他工具与依赖以 SKILL.md 中的要求为准。

## 输入与输出

**输入：** 同一份商品事实资料、目标受众与平台要求。

**输出：** 基于同源事实的口播、小红书和公众号内容及结果记录。
